## 1 — المبدأ الحاكم: الإفصاح التدريجيّ المقود بـ«من أنت؟»

**الفجوة المفصليّة (مُتحقَّقة في الكود):** مُنتقي «من أنت؟» (`index.html:520-527`؛ خمسة أدوار: مالك/مشتري/بائع/مستثمر/مثمّن) يُبَثّ للخادم عبر `selAud` (سطر 833) لكنه **عرضيّ بحت** — يُطبّع `owner→buyer` ويُقسّم أقسام الـbrief فقط، **ولا يُكثّف/يُخفّف كثافة شاشة النتيجة.** هذا المُنتقي المُهمَل = **العمود الفقريّ** للحلّ.

**القاعدة الواحدة:** «من أنت؟» يصير مفتاح **كثافة العرض عند رسم النتيجة**.
1. **نواة عالمية واحدة:** الجميع يرى أولاً **٥ عناصر فقط** — النطاق + الوسيط + «ليس تقييماً معتمداً» + سطر جودة-أدلّة واحد (pill) + زر «كيف وصلنا للرقم؟».
2. **العمق opt-in:** «موكب التسعة» **لا يظهر أبداً** على TIER-1 — كله خلف أكورديون واحد.
3. **القيمة ثابتة، الكثافة متغيّرة** (مبدأ b24 «الرقم واحد للجميع» محفوظ — غير قابل للتفاوض). ما يتغيّر بالدور = **حالة الطيّ الافتراضية + ترتيب الأقسام + المخرج الأساسيّ**:
   - **مالك/بائع/مشتري** → الملاحظات الفنية **مطويّة افتراضياً**.
   - **مستثمر/سمسار/مثمّن/مهندس/صحفي** → أكورديون «الملاحظات الفنية» **مفتوح**، كثافة أعلى، «الأدلّة أولاً».
   - **محامٍ/مدقّق-بنك/ورثة** → عرض امتثاليّ (MUC+tier+n+freshness+النطاق) + إخفاء الحاسبة/السيناريوهات/الهندسة + المخرج الأساسيّ = **التقرير الكامل** لا المختصر.

> **الجملة:** «المالك البسيط يرى إجابة من ٥ عناصر؛ العمق بنقرة؛ المتخصّص يولد بالكثافة مفتوحة.»

## 2 — مصفوفة الحِمية

**النواة المشتركة (يراها الجميع أولاً):** النطاق · الوسيط · «ليس تقييماً معتمداً» · سطر جودة الأدلّة الواحد (n + ثقة) · زر «كيف وصلنا للرقم؟». (بانر MUC يبقى مرئياً؛ كلمة المستوى تنزل للأكورديون ما لم تكن «حرجة».)

| الدور | الدلتا فوق النواة (first-view) | يُخفى عن العرض الافتراضيّ |
|---|---|---|
| **المالك/البائع** (الأهمّ) | لا شيء — النواة فقط | الموكب التسعة كله · شارة tier · سطر التشتت · رقاقة MUC غير-الحرجة · ملاحظات resurvey/HBU/value-floor · multi-QARS لقطعة مفردة · أرقام الكهرباء/الماء |
| **المشترية المموّلة** | سعر/م² + **حاسبة تمويل** أسفل الرقم | الموكب · §4/§5 المختصر · تنبيهات لا تخصّها · n بخطّ بارز |
| **المستثمر** | شارة العائد (gross/net) + سطر القائد | تنبيهات روتينية · subtype-zoning · asset-reality · tower-pair · معادلة الارتدادات |
| **السمسار** | سطر القائد الواحد + CTA مشاركة + شارة «متّصل» (طزاجة) | شارة tier · المنهجية النثرية · تحذير الافتراض النموذجيّ · شرح توسيع النطاق |
| **المحامي** | السقف القانونيّ/النطاق المدعوم + caveat طزاجة | كل افتراضات الأعمال · الموكب على TIER-1 · per-m² · رموز أسباب الرفض |
| **المدقّق/البنك** | **MUC + بند عدم اليقين كاملاً** + شريط أساس مختصر | الهندسة كلّها · زرّ refine · المعالم/الزاوية · المختصر النثريّ (← شهادة صفحة) |
| **الورثة** | الرقم العادل + n + طزاجة + MUC + **QR/مرجع مانع للتلاعب** | إطار التفاوض كله (×0.90/×1.10/×1.30) · الحاسبة · السيناريوهات · refine · (المخرج = التقرير الكامل) |
| **المثمّن** | tier + رقاقة MUC + صفّ الأدلّة بـn لكل مكوّن | الحاسبة · سيناريوهات الكلفة · نثر المختصر التسويقيّ + hero + سطر الواتساب |
| **الصحفي** | شارة المنهج (cost/market/income-led) | الزبدة العملية · الحاسبة · سيناريو الفخامة · أعلام الحالة الخطابية |
| **المهندس** | tier + عنوان أكورديون يحمل العدّ (الأدلّة·12 / الأساس·8) | نثر القائد · الملاحظات الفنية منفردة (← داخل الأكورديون) · حاسبة التمويل |

**الخلاصة:** النواة الخمسية تخدم الجميع. الدلتا الحقيقية لكل دور = (أ) **عنصر قرار إضافيّ واحد** + (ب) **حالة الطيّ** + (ج) **المخرج الأساسيّ**.

## 3 — قائمة قتل الإرباك للمالك البسيط (TIER-1: 21 → 5)

كل ما يلي يُنقَل خلف أكورديون «كيف وصلنا لهذا الرقم؟» (مطويّ افتراضياً للمالك):

**من النتيجة:** (1) value-floor · (2) HBU · (3) old-stock re-anchor · (4) cost-triangulation · (5) نثر القائد (→ سطر واحد بالأكورديون) · (6) age-honesty · (7) resurvey · (8) cost-value-stack (إلا cost-led → سطر واحد) · (9) سطر التشتت · (10) رقاقة MUC (تبقى بانراً؛ الكلمة بالأكورديون ما لم تكن حرجة) · (11) شارة tier (→ تسمية باهتة برأس الأكورديون) · (12) لوحة الأدلّة الكاملة (→ سطر pill واحد) · (13) age-sensitivity · (14) multi-QARS لقطعة مفردة · (15) subtype-zoning · (16) tower-pair-ignored.

**من التأكيد:** (17) معادلة الارتدادات E15 (يبقى رقم الحدّ الأقصى + CTA «عدّله»؛ المعادلة tooltip) · (18) لوحة الأدلّة الكاملة (→ أكورديون النتيجة) · (19) فترة المسح (→ تلميح حقل العمر في refine) · (20) أرقام المرافق (ما لم تُطلب).

**يبقى على التأكيد للمالك:** مراجعة الأساس (عنوان/zone/area) + نطاق مبدئيّ باهت + زرّ تأكيد + هروب «التقرير الكامل». لا لوحة أدلّة، لا معادلات.

## 4 — إعادة تصميم مدخل البيانات

**المشكلة:** عبء الهُويّة مُقدَّماً — تبويب (عنوان/PIN) + ثلاثة أرقام منفصلة + لوحة مفاتيح جوّال + اختيار دور. مبدأ **E17** (حقل-واحد-أدنى: «اسأل مرة، اجلب كل شيء، اعرض للمراجعة») مُنتهَك بثلاثة حقول.

| الرتبة (ROI) | الخيار | الجهد | الأثر | قدرة GIS | الفئة |
|---|---|---|---|---|---|
| **1 فوريّ** | **D — افتراضيّ + سطر مساعدة** (نقاش أدناه) | 30د | منخفض-متوسط | لا شيء | frontend / Gate-1 |
| **2 المُوصى به** | **C — إكمال تلقائيّ منسدل** (zone→street→building من JSON ثابت من `QARS_Point`) | 2-3س | متوسط-عالٍ | `QARS_Point` مُفرَّغ | frontend (+ pipeline) |
| **3** | **A — حقل ذكيّ واحد** (parse → address/PIN/area) | 4-6س | عالٍ | QARS+Cadastre+Districts (fuzzy) | engine / Gate-2 |
| **4 (E17، الأعلى مكسباً)** | **B — دبّوس خريطة (GPS tap → centroid → PIN)** | 8-12س | الأعلى | `CadastrePlots` spatial (مُختبَر) | frontend(Leaflet)+engine / Gate-2 |

**القيد المعماريّ:** كل خيار جديد يجب أن يجتاز **بوّابة #46** (audit سلسلة input→API→engine→classifier asset_type→trigger قبل الشحن). **ملاحظة جوّال 390px:** المنسدلات الأصليّة (C) تتفوّق على إدخال النصّ (نظام التشغيل يدير الـUX ويُلغي قفز لوحة المفاتيح ~50% من الشاشة).

## 5 — خطة سبرنتات مُرحَّلة (DEF-UX11 → UX18) + التسلسل

التسلسل: **UX11 (الطيّ — وحده يخفض الحمل ~80% للجميع)** → UX13 (التأكيد) → UX14 (مدخل سريع) → **UX12 (الكثافة المقودة بالدور — المفصل)** → UX16 (حاسبة المشتري) → UX15 (إكمال تلقائيّ) → UX17 (مسار قانونيّ/بنكيّ) → UX18 (حقل ذكيّ) → B (backlog). التفصيل في `ISSUES_LOG §4ب`.

**ملاحظتان حاكمتان:**
- **القيمة ثابتة عبر كل الأدوار** (b24) — كل سبرنتات الكثافة value-invariant بالبناء؛ Gate-2 لا ينطبق إلا على UX17/UX18/B (تسميات أدوار جديدة أو نقطة محرّك جديدة).
- **DEF-UX12 هو المفصل:** أصغر تعديل خادم (بثّ `audience` في الاستجابة، additive) يفتح كل الإفصاح التدريجيّ المقود بالدور أمام الـfrontend.
