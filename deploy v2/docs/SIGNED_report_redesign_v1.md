## §0. القرار الحاكم
1. **تدرّج وطيّ:** الوجه الأول = ٥ ثوانٍ، وكلّ الباقي (الامتثال/العمق) خلف **صفّ «عرض التفاصيل» واحد** — **لا يُحذف شيء**، يُطوى فقط.
2. **قيمة‑ثابتة:** لا مساس بـ amount/low/high/method/rule؛ أيّ «محرّك يُحرّك الرقم» (الواجهة/الحالة→القيمة) = **بوّابة Gate‑2 منفصلة مستقبلاً**.
3. **الشامل يفتح بنفس وجه الملخّص** ثم يتعمّق (منتج واحد بمستويين).
4. **سطر القرار = الخيار (ب):** أُسقِط «سقف الشراء المخصّص»؛ **النطاق + علامة الوسيط** يؤدّيان دور القرار؛ **العُرف العامّ المتماثل** (+١٠٪/+٣٠٪) في «التفاصيل» فقط، بلا رقم مخصّص.
5. **التسمية والقانون ٢٨/٢٠٢٣ = بند مفتوح للمستشار** (انظر §10). نعتمد الآن **التحصين الآمن**: ذكر القانون صراحةً في السطر القانونيّ + تجنّب «مثمّن معتمد» و«القيمة العادلة» لمخرجاتنا.

## §1. الوجه الأول (الملخّص + رأس الشامل) — يجيب ٣ أسئلة
**كم يساوي؟ / لماذا؟ / أين يقع؟** — بالترتيب البصريّ من الأعلى:
1. **الرقم الكبير** + **سعر القدم المربّع** تحته مباشرةً (`~ X ر.ق/قدم²`) + **النطاق** (شريط بعلامة الوسيط) + **تاريخ التقييم**.
2. **مؤشّر الثقة** (سلّم §3 — كلمة + عدد الصفقات).
3. **صفّ ٥ شارات** (§2).
4. **سطر قانونيّ مضغوط** (§5 — counsel).
5. **صفّ «عرض التفاصيل» واحد** (§4).

> **سعر القدم (Gemini r3):** السوق القطريّ يتداول بالقدم والعدل يسجّل بالمتر — إبرازه إلزاميّ. المصدر عندنا (`median_ft` + الاشتقاق من amount/area).

## §3. سلّم الثقة (عتباتنا E4 + ألفاظ Gemini + إخفاء المركزيّ عند الشحّ)
| عدد الصفقات n | اللفظ | السلوك البصريّ |
|---|---|---|
| **n ≥ ٢٠** | 🟢 مطابقة عالية (n صفقة) | الرقم المركزيّ واضح + نطاق ضيّق |
| **١٠–١٩** | 🟡 مؤشّر إرشاديّ (n صفقة) | مركزيّ واضح + نطاق متوسّط |
| **٥–٩** | 🟠 تقدير تقريبيّ (بيانات محدودة: n) | مركزيّ رماديّ + تركيز على النطاق |
| **n < ٥ (وله قيمة)** | 🔴 نطاق سعريّ فقط | **يُخفى الرقم المركزيّ** → «القيمة المتوقّعة بين X و Y» |

> عتباتنا الموقَّعة (n≥٢٠ موثوق … <٥ غير كافٍ، قاعدة E4) مُبقاة كما هي؛ أخذنا **ألفاظ Gemini + سلوك «نطاق فقط عند الشحّ»** (متّسق مع b3 range‑as‑lead). أيّ تغيير للعتبات الرقمية = قرار منهجيّ صريح، لا تلقائيّ. مسارات الرفض (amount=None) دون تغيير.

## §5. الصياغات (Microcopy) — مسودّة تمرّ على المحامي/اللغويّ + counsel للقانونيّ
- **السطر القانونيّ (Gemini r3، counsel‑pending):**
  > «مؤشّر سعريّ استرشاديّ آليّ يعتمد على صفقات تاريخية علنية، ولا يُعدّ تقريراً تقييمياً رسمياً أو تثميناً معتمداً وفقاً للقانون رقم (٢٨) لسنة ٢٠٢٣ بتنظيم أعمال التقييم العقاري في دولة قطر.»
- **ألفاظ الثقة:** كما في §3.
- **أمثلة شارات:** أرض `التصنيف: سكني R1` · `الواجهة: ١٥٫٥م` · `المساحة: ٦٠٠م² (٦٬٤٥٨ قدم²)` · `شوارع: زاوية` · `الحي: الثمامة (Zone 46)` — فيلا `البناء: ~٥٥٠م² (تقديريّ)` · `العمر: ~٥ سنوات` · `الملاحق: مجلس + ملحق` · `التشطيب: ديلوكس (افتراضيّ)` · `الأرض: ٤٥٠م²`.
- **شارة الفرز (م٢):** «مؤشّرات الأرض تتيح الفرز مبدئياً لـ N قطع — يخضع لقوانين الارتدادات وموافقة التخطيط العمرانيّ بوزارة البلدية».

### §5.1 — تحديثات جولة جيميناي ٥ (المُعتمَدة بعد المحامي/اللغويّ + أحكام Rule #54)
**✅ اعتُمد من جيميناي (١٣ بنداً):**
1. **ترتيب الكتل يبقى** (رأس ← هيرو ← ثقة ← شارات ← قانونيّ ← طيّ) — «التسلسل الإدراكي الطبيعيّ».
2. **عنوان الهيرو موحّد محايد (قرار المالك 2026-07-01):** **«القيمة السوقية التقديرية»** لكلّ الجمهور — أوقع مهنياً وأحيد (اختيار Gemini)؛ يستبدل «قيمة بيتك التقديرية اليوم» (عقد b28) في المختصر.
3. **n<٥:** «بيانات شحيحة» → «بيانات مقارنة محدودة جداً» (رفع الدلالة السلبية).
4. **«الملاحق: —»** → «الملاحق: غير محدّدة» + أيقونة قلم `ic-edit` (الشرطة توحي بخطأ نظام).
5. ⭐ **نطاق سعر القدم** بخطٍّ صغير تحت شريط النطاق: «نطاق سعر القدم: ~{low_ft} — ~{high_ft} ر.ق/قدم²» — `low_ft=round((low/area_m2)/10.764)`، `high_ft=round((high/area_m2)/10.764)` — «بلسان السوق القطريّ». **value-invariant** (اشتقاق عرضيّ). (الوعب: ~٤٠٤ — ~٦٤٨.)
6. **تقصير الشارات:** إسقاط «(قدم²)» من شارة المساحة (موجودة في الهيرو) · «الشوارع: زاوية» → «أرض زاوية»؛ تبقى ٥ (تلتفّ flex-wrap بلا overflow).
7. **السطر القانونيّ (صياغة جيميناي الأنسب، أيقونة `ic-alert` لا إيموجي، counsel-pending):** «هذا المؤشّر السعريّ ناتج عن تقييم سوقيّ آليّ استرشاديّ يعتمد على صفقات وزارة العدل التاريخية العلنية، ولا يُعدّ تقريراً تقييمياً رسمياً أو تثميناً معتمداً وفقاً لأحكام القانون رقم (٢٨) لسنة ٢٠٢٣ بتنظيم أعمال التقييم العقاري في دولة قطر.»
8. **n<٥ (بديل الهيرو عند حجب الرقم المركزيّ):** «لقلّة الصفقات المسجّلة في هذه الشريحة، اعتمد على النطاق السعريّ أدناه كدليل استرشاديّ». (صُحِّح سبب جيميناي «تذبذب» → «قلّة الصفقات»: الشحّ لا التذبذب.)
9. **الشامل — ترتيب «الأدلّة الباردة» proof-first (يستبدل §7):** ١) جدول الصفقات المقارنة ← ٢) كشف معاملات التعديل ← ٣) كيف وصلنا (السرد) ← ٤) اتجاه المنطقة ← ٥) الملحق القانونيّ. (المثمّن/البنك يريد الإثبات أولاً.)
10. **الشامل — جدول الصفقات:** الوحدة «م²» في **رأس العمود**، الخلايا أرقام مجرّدة (Scannability).
11. **الشامل — معاملات التعديل:** النِّسَب في جزر `dir=ltr` (Rule #25) لمنع تداخل +/×؛ دمج «صيدلية·مطاعم ٠٫٥٪×٢» → «+١٫٠٪ (قرب صيدلية ومطاعم)».
12. **«عرض التفاصيل» = سهم لأسفل** `chevron ▾` (يدور للأعلى عند الفتح) لا سهم جانبيّ (أفوردانس أكورديون رأسيّ).
13. 🔴 **شريط النطاق (حرج):** نقطة الوسيط عند موضعها الحقيقيّ `(amount−low)/(high−low)` — يُبنى **كخطّ أرقام LTR** (الأدنى يساراً ← الأعلى يميناً) تفادياً لالتباس RTL الذي رصده جيميناي.

**🔧 عُدِّل/رُفِض (Rule #54 — أحكام صدق تفوق تحذير AI):**
- «اعتباراً من» → «تاريخ التحديث الآلي» **مرفوض** (يوهم بحداثة البيانات وهي مجمّدة عند ٣١ ديسمبر ٢٠٢٥ / ١٨٢ يوماً) → نُبقي **«تاريخ التقييم: {date}»** (الموقَّع، الصادق — تاريخ إصدار التقدير لا تحديث البيانات).
- توحيد «القيمة السوقية التقديرية» → **اعتمده المالك موحَّداً محايداً للجميع** (بند ٢، قرار 2026-07-01).
- **كلّ الإيموجي (📝 ⚠️) → أيقونات `ic-*`** (قفل صفر-إيموجي b48/b74/b76).
- ترقيم أقسام الشامل: **أصلاً هنديّ** في الوضع العربيّ (`t('١','1')` + `fmt` بـ ar-QA) — لا إجراء، يُتحقَّق في R14.

## §6. ميزة الفرز (م٢ — منطق برمجيّ، Gemini r3)
```
IF (المساحة_الإجمالية ≥ 800 م²) AND
   (أطول_واجهة_مستمرة ≥ 24م  OR  (زاوية AND واجهة_أ ≥ 12م AND واجهة_ب ≥ 12م))
THEN N = MIN( FLOOR(المساحة/400) , FLOOR(أطول_واجهة/12) ) ; "قابلة للفرز مبدئياً"
ELSE "قطعة مفردة"
```
- **لا نجمع أطوال الواجهات** (خطأ برمجيّ — لا فرز لقطعة خلفية بلا شارع)؛ كلّ قطعة ناتجة تحقّق المساحة **و**الواجهة معاً. عتبات: ٤٠٠م²/١٢م/٢٤م.
- يتطلّب **اشتقاق الواجهة هندسياً** من مضلّع القطعة + الشوارع المجاورة (`corner_analysis`) → **م٢**. عرض فقط، لا يمسّ الرقم. صياغة حذرة (ادّعاء شبه‑قويّ).

## §7. التقرير الشامل — نفس الوجه ثم ٤ أقسام «أدلّة باردة» للبنك/المثمّن (Gemini r2)

2. **اتجاه المنطقة ٢٤ شهراً** (سعر + سيولة/عدد الصفقات).
3. **كشف معاملات التعديل** (كيف عدّل النظام: +زاوية، −عمر…).
4. **الملحق القانونيّ + RICS/IVS كامل** غير مجتزأ.
