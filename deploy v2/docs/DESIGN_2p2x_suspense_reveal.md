## ١. المبدأ الحاكم (غير قابل للتفاوض)
- ما **يرتفع** عبر القوس = **العمق والشواهد والثقة في التحليل** — لا الرقم، ولا الإحساس باليقين.
- **الخطر المحوري (من التحكيم):** تراكم الشرح يضخّم الإحساس باليقين ولو لم تُضَف معلومة. لذا قاعدة صارمة:
  **الشرح ≠ ثقة** — المؤشر يرتفع **فقط** بمدخل حقيقي يُقلّل عدم اليقين (هندسة يستخدمها المحرّك)؛
  الشرح (GIS، تفكيك، تصنيف، اتجاه) **لا يرفعه**، يُعرَض كعوامل تُشكّل النطاق.
- الرقم دائماً **نطاق** (لا نقطة قط) بتحفّظ سليم. **لا** عدّاد «جاكبوت» يتسلّق للإثارة.
- لا «ثقة» مفردة — بل **تشخيص مكوّنات** (§٣). التحفّظات **إطار دائم** من الشاشة الأولى.

## ٢. وضعان حسب الجمهور
- **مهنيّ (مُقيّم):** الافتراضي = **التقرير الكامل/المسار السريع** (لا «ساحر»)؛ يفتح الكشف المرحلي اختيارياً.
- **مالك/مشترٍ/بائع/مستثمر:** الافتراضي = **الكشف المرحلي** التثقيفي + «التقرير الكامل الآن» **خيار مكافئ دائم**.
- بمُحدّد الجمهور الموجود. والحواجز أدناه تنطبق على الكشف في الحالتين.

## ٣. نموذج الثقة = تشخيص مكوّنات (بديل «٧٠٪»)
بدل رقم مفرد: لوحة — **اكتمال بيانات العقار · جودة المقارنات · حداثة بيانات السوق · جودة توصيف المبنى**
(قوي/متوسط/محدود).
- يتحسّن مكوّن **فقط** بمدخل حقيقي يخصّه (الهندسة → «التوصيف»). الشرح لا يحرّك أيّ مكوّن.
- **الحالة (غير متحقّقة) لا تُقوّي مكوّناً** — تبقى «محدودة/غير متحقّقة» وتعمل كـ**حساسية** على النطاق فقط
  (R7/B-2 معلَّقة، لا معاينة).
- التشخيص حاضر **من الفصل ١** ← هكذا يدخل عدم اليقين مبكراً (يُظهر الفجوات فوراً).
- **[ملاحظة §٣]** هذه لوحة **جودة-أدلّة**، لا تفكيك قيمة. تفكيك الأرض/البناء مكانه الفصل ٤ (تالياً).

## ٤. الفصول — مؤطَّرة بالقرار، عدم اليقين مبكراً  *(للمالك؛ المهنيّ يقفز للتقرير)*
- **١) ماذا نعرف؟** التعريف ← تقدير مبدئي (**نطاق**) + تشخيص المكوّنات (يُظهر الفجوات) + الإطار الدائم.
  *(يبدأ صغيراً، عدم اليقين حاضر — تفكيك أدنى)*
- **٢) ما الذي قد يجعلنا مخطئين؟** «ما لا نعرف (يحتاج معاينة)» + المخاطر — **مبكراً، قبل عمق الأدلّة**
  فلا يصير القوس تصاعداً نحو اليقين.
- **٣) ما الذي يمكن تحسينه؟** الصقل: **هندسة** (يستخدمها المحرّك ← تحسين حقيقي + تحديث «التوصيف»)؛
  **الحالة/العمر/التشطيب ← حساسية** («لو كذا يزيح النطاق ±»، الثقة ثابتة)؛ المالي (السعر/الإيجار، اختياري)
  يُثري لاحقاً بلا رفع ثقة.
- **٤) لماذا هذا النطاق؟** الأدلّة المفسِّرة: **تفكيك أرض/بناء** (بتحفّظ «تحليلي غير متحقّق» — موجود) +
  المقارنات (n) + العائد + التصنيف + GIS + الاتجاه. **كلّها شرح — لا ترفع الثقة.** *(اغتناء بلا تضخيم يقين)*
- **٥) كيف تُقرأ النتيجة؟** RICS/IVS كامل + «ليس تثميناً رسمياً» + حدود الاستخدام + توصية مُقيّم >٥م.
  ثم **التقرير الكامل** كأثر.
- العدد (٥ أم دمج ٣–٤) = ضبط مفتوح (تحذير القمع قائم).

## ٥. آلية الكشف
شاشات منفصلة للمالك (تحقيقاً لـ«على مراحل، ليس في نافذة واحدة») بانتقال أنيق سريع · «التقرير الكامل الآن»
**خيار مكافئ دائم** (لو مرّ ٩٥٪ قسراً = قمع) · إيقاع يتحكّم به المستخدم.
