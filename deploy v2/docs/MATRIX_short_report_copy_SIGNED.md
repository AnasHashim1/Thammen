**ثوابت النسخ الأربع:**
1. الجبري ×0.90 (D2).
2. سطر القسط بالافتراضات الثلاثة (دفعة أولى 20% · مدة 25 سنة · فائدة 4.5%) **قابلة التعديل داخل السطر نفسه** — لا إدخال مسبق + «استشر بنكك» (D3 المعدلة).

4. الكتلة القانونية حرفية (+IFRS 13) — نص الشاشة ٧ في عقد v3:
